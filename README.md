Sistema de Triagem e Avaliação de Pacientes

Projeto prático desenvolvido em Java para a Unidade Curricular (UC) de Algoritmos e Programação (Centro Universitário UNA), estruturado através da plataforma DreamShaper.

Sobre o Projeto

O sistema simula um módulo de atendimento e triagem clínica executado via console. Ele permite cadastrar dados básicos de pacientes, calcular automaticamente o Índice de Massa Corporal (IMC) e apresentar a classificação nutricional correspondente de forma contínua até que o usuário opte por encerrar a execução.

Conceitos Aplicados

Entrada e Saída de Dados: Leitura interativa via terminal utilizando a classe Scanner e formatação de saída com System.out.printf.

Estruturas de Repetição: Controle de fluxo do menu principal com o laço while.

Estruturas Condicionais: Validação das opções do menu e classificação dos resultados de IMC utilizando if / else if / else.

Modularização (Métodos): Separação de responsabilidades em métodos específicos (calcularIMC e exibirFichaPaciente) com passagem de parâmetros e retorno de valores.

Tecnologias Utilizadas

Linguagem: Java (JDK)

IDE: IntelliJ IDEA Community Edition

Como Executar o Projeto

Certifique-se de ter o Java Development Kit (JDK) instalado em sua máquina.

Clone este repositório ou baixe o arquivo Main.java.

Abra o projeto no IntelliJ IDEA (ou em sua IDE Java de preferência).

Execute o método main da classe Main.java e siga as instruções exibidas no console.
